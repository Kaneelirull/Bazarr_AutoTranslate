PROJECT: Bazarr AutoTranslate
PURPOSE: Translate Bazarr-managed subtitle sidecars through Lingarr with validation, recovery, retry, maintenance, and a read-only dashboard.
STACK: Python 3.11, SQLite, requests, lingua-language-detector, Docker
DEPLOY: bazarr-autotranslate container, typically alongside Lingarr on TrueNAS SCALE

STRUCTURE:
docker/Bazarr_AutoTranslate.py - permanent Docker bootstrap and compatibility alias
docker/autotranslate/app.py - intended production composition root
docker/autotranslate/runtime.py - legacy combined runtime being removed
docker/autotranslate/services/ - Bazarr, Lingarr, and HTTP adapters
docker/autotranslate/scheduling/ - capacity, retry, repair, circuit, lock, and executor coordination
docker/autotranslate/subtitles/ - parsing, validation, recovery, sidecars, and quarantine
docker/autotranslate/maintenance/ - retention, library scan, pruning, and legacy indexing
docker/autotranslate/persistence/ - SQLite state, migrations, database, and repositories
docker/autotranslate/status/ - privacy facade, tracker, server, logging, and dashboard rendering
tests/ - unittest unit, integration, architecture, migration, shutdown, and recovery coverage

ENTRY POINTS:
/app/entrypoint.sh -> python3 -u /app/Bazarr_AutoTranslate.py -> autotranslate.app.main
docker/clean_et_subs.py -> standalone cleanup CLI compatibility entry
